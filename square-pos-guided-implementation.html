1. Pre-installation menu review
0 / 3 tasks
Why this matters: Before touching Square, you need to align with the seller on what they're selling. A poorly prepared menu causes rework — items missing, wrong prices, or the seller requesting major changes after setup. This section ensures you start on solid ground.
Sit down (or screen share) with the seller and their team to review every item, modifier, and category they want on the POS. Take notes — don't rely on memory.
  1. 1Schedule 30–60 min with the seller before install day
  2. 2Ask for their existing menu (printed, PDF, or website link)
  3. 3Walk through each section: food, drinks, modifiers, combos
  4. 4Note any items that are seasonal or location-specific
  5. 5Ask about pricing — are all variations and sizes priced correctly?
💡Rep tip: Ask: "Is there anything on your current menu that's changing soon?" This prevents you from loading items they'll immediately want to remove.
Get explicit sign-off that the menu is ready to go. Changes mid-install waste everyone's time and can introduce errors.
  1. 1Email or message the seller: "Is your menu finalized and ready to load?"
  2. 2If they say "mostly" — push for full sign-off before you begin
  3. 3Document their confirmation (screenshot or email is fine)
💡Rep tip: It's normal for sellers to want to add "just one more thing." Set expectations: bulk changes are easy before install, painful after.
Empower the seller to manage their own menu going forward. Walk through Dashboard menu creation and editing so they're not dependent on you for every change.
  1. 1Sign in to Square Dashboard
  2. 2Go to Items & Orders → Menus
  3. 3Click Create Menu — enter a name, select locations
  4. 4Add categories and items to the menu, then click Save
  5. 5To edit: return to Menus, select the menu, make changes, Save
💡Rep tip: Show them the Edit POS layout too — sellers are often surprised they can customize how items appear on the screen.

2. Items & catalog
0 / 4 tasks
Why this matters: The item library is the backbone of the POS. Every product the seller sells needs to be here — with the right name, price, and configuration. Rushing this section leads to incorrect orders and confused staff on day one.
Add each product the seller sells as an item in Square Dashboard. Items can also be created directly from the POS app if needed.
  1. 1Dashboard → Items & Orders → Items → Create Item
  2. 2Enter Item Name (required)
  3. 3Enter Price
  4. 4Add Description (helps staff identify the item)
  5. 5Assign a Category (optional but recommended)
  6. 6Add an image if available
  7. 7Assign locations where the item will be sold
  8. 8Click Save
💡Rep tip: Use the bulk import (CSV) if the seller has 20+ items — it's much faster than entering them one by one. See the Data Imports section.
Create and edit items ↗ Bulk import items ↗
Modifiers let customers customize items (e.g. sauce choices, add-ons, cooking preferences). Set these up before linking them to items.
  1. 1Dashboard → Items & Orders → Modifiers → Create Modifier Set
  2. 2Name the set (e.g. "Sauce Options", "Add-ons")
  3. 3Add each modifier choice (e.g. Ranch, Blue Cheese, BBQ)
  4. 4Set pricing for each choice if applicable
  5. 5Set minimum and maximum selections
  6. 6Toggle Required on if the customer must pick at least one
  7. 7Open each item → scroll to Modifier Sets → select the set → Save
💡Rep tip: Keep modifier set names generic so you can reuse them across multiple items. "Protein options" can apply to salads, bowls, and sandwiches.
Create and manage modifiers ↗ Modifiers with Square for Restaurants ↗
Variations are different versions of the same item — like Small, Medium, Large or 8oz, 16oz. Each variation can have its own price.
  1. 1Open an item in Dashboard
  2. 2Under Variations, click Add Variation
  3. 3Enter variation names (Small, Medium, Large)
  4. 4Assign a price to each variation
  5. 5Add SKU or barcode if tracking inventory
  6. 6Click Save
💡Rep tip: Don't confuse variations with modifiers. Variations are mutually exclusive (a customer picks ONE size). Modifiers can allow multiple selections.
Create and edit item options & variations ↗
Categories organize items on the POS screen and in reports. Good category structure makes it easy for staff to find items quickly during a rush.
  1. 1Dashboard → Items & Orders → Categories → Create Category
  2. 2Enter a category name (e.g. "Burgers", "Beverages", "Desserts")
  3. 3Click Save
  4. 4Open each item and assign it to the correct category from the Category dropdown
💡Rep tip: Plan category names with the seller before creating them. Changing category names later doesn't break anything, but it creates confusion for trained staff.

3. POS layout
0 / 1 tasks
Why this matters: The POS layout is what the seller's staff sees every day. A well-organized layout means faster transactions, fewer mistakes, and happier staff. A cluttered one creates friction on every single sale.
The POS layout controls where items appear on the grid when staff are ringing up orders. You can organize by category, create shortcuts, and set up a logical flow.
  1. 1Sign in to Square Dashboard
  2. 2Navigate to Items & Orders
  3. 3Click Edit POS (or Point of Sale Layout — name varies by account type)
  4. 4Select the location you're configuring
  5. 5Drag and drop items or categories into the grid
  6. 6Set up Favorites for the seller's most common items
  7. 7Adjust column count and spacing if needed
  8. 8Click Save, then Publish if prompted
💡Rep tip: Ask the seller: "What are your top 5 selling items?" Put those in the top-left of the grid — that's where staff look first.

4. Taxes & service charges
0 / 2 tasks
Why this matters: Incorrect tax setup can create compliance issues and erode seller trust fast. Always verify taxes are correctly applied and run a test transaction before going live.
Square lets you create tax rates and apply them to items. Check that the right rate is set for the seller's location and applied to all taxable items.
  1. 1Dashboard → Settings → Business → Sales Taxes
  2. 2Confirm the tax rate name and percentage are correct for the seller's jurisdiction
  3. 3Open Items and select a few items across categories
  4. 4Review the Taxes section on each item — confirm the correct tax is toggled on
  5. 5Run a test transaction on the POS
  6. 6Check the order summary to confirm tax calculates correctly before completing payment
💡Rep tip: Some items may be tax-exempt (e.g. grocery staples, certain beverages depending on state). Ask the seller if they have any non-taxable items before you finish.
Create and manage sales taxes ↗ Conditional tax rules ↗
Service charges are automatic fees added to orders — like an 18% gratuity for large parties or a delivery fee. Only configure if the seller uses them.
  1. 1Dashboard → Account & Settings → Checkout → Service Charges (path may vary by product)
  2. 2Confirm charge name, type (percentage or flat amount), and applicable locations
  3. 3Run a test transaction
  4. 4Verify the service charge appears on the order summary before payment
💡Rep tip: Not every seller uses service charges. Ask first. If they do, make sure they understand how it differs from a tip — some sellers confuse the two.

5. Inventory tracking
0 / 3 tasks
Why this matters: Inventory tracking is optional but valuable for sellers who want to avoid overselling or get low-stock alerts. Set it up only if the seller opted in — don't enable it without their knowledge.
Confirm that inventory tracking is turned on for items that need it, and that opening stock counts are entered correctly.
  1. 1Open an item in Dashboard
  2. 2Go to the Inventory section
  3. 3Confirm Track Inventory is enabled (toggle is on)
  4. 4Verify the current stock quantity is correct
  5. 5Check stock adjustment history if any prior adjustments exist
  6. 6Save any changes
💡Rep tip: Before entering stock counts, ask the seller: "Have you done a count recently?" If not, schedule a physical count before you input quantities.
Track inventory with Square ↗ View, receive & adjust inventory ↗
SKUs and barcodes let staff scan items rather than searching for them. Critical for retail sellers with large catalogs.
  1. 1Open an item in Dashboard
  2. 2Select the variation
  3. 3Confirm the SKU is entered and is unique across all items
  4. 4Locate the GTIN/Barcode field
  5. 5Verify the barcode number matches the physical product label
  6. 6Test scan the barcode using the POS scanner
  7. 7Confirm the correct item populates automatically on screen
💡Rep tip: SKU values can get corrupted when opening CSV files in Excel. If imported SKUs look wrong, open the CSV in a plain text editor to check the raw values.
Set up inventory tracking (SKU/GTIN) ↗ Troubleshoot item library importing ↗
Low-stock alerts notify the seller when an item falls below a threshold. Great for items that frequently run out.
  1. 1Dashboard → Items & Orders → Inventory Management
  2. 2Open the item or variation
  3. 3Enable inventory tracking if not already on
  4. 4Enter a Low Stock Threshold (e.g. 5 units)
  5. 5Click Save
  6. 6Verify alert notifications are enabled in notification settings
  7. 7Test by temporarily adjusting stock below the threshold and confirming the alert triggers
💡Rep tip: Ask the seller: "What quantity means you need to reorder?" Use that number as the threshold — not zero.

6. Data imports
0 / 4 tasks
Why this matters: Bulk imports save hours compared to manual entry. Use them when a seller has existing data — menus, customer lists, items, vendors. Always use Square's templates and verify data after import.
If the seller is moving from Toast, Olo, or another platform, WoFlow can migrate their menu directly. This saves hours of manual entry.
  1. 1Dashboard → Items & services → Menus
  2. 2Click Create a menu → Import your menu from another platform
  3. 3In the WoFlow modal, select the seller's current platform
  4. 4Choose import method: sign in securely or share a public URL
  5. 5Click Continue to sign in to the source platform
  6. 6Let the menu import — review progress
  7. 7Review the imported menu carefully, make edits if needed
  8. 8Click Approve to finalize
💡Rep tip: Always review the imported menu with the seller present. Item names, prices, and modifiers often need cleanup after import.
Create and update menus ↗ Manage menus across locations ↗ Edit Square Kiosk menus ↗
For sellers with 20+ items, import via CSV or Excel instead of entering each item manually. Required columns: Item Name, Variation Name, Description, SKU.
  1. 1Dashboard → Items & services → Items → Item library
  2. 2Click Actions → Export Library
  3. 3Download either the blank template or an export of existing items
  4. 4Fill in the spreadsheet — do NOT reorder or delete columns
  5. 5Required columns: Item Name, Variation Name, Description, SKU
  6. 6For multi-location accounts, add Enabled [Location Name] column
  7. 7Return to Item library → Actions → Import library
  8. 8Upload the file, confirm column matching, complete the import
💡Rep tip: Open the CSV in Google Sheets instead of Excel to avoid SKU formatting issues. Excel sometimes converts numeric SKUs to scientific notation.
Bulk import items ↗ Troubleshoot item library importing ↗
If the seller has an existing customer list, import it so they can start using Square's loyalty, marketing, and CRM tools immediately.
  1. 1Customers → Customer directory → Directory
  2. 2Click Import/Export → Import customers
  3. 3Click Download template (or Next if file is ready)
  4. 4Upload the prepared file and click Next
  5. 5Review and assign the column fields (name, email, phone, etc.)
  6. 6Click Import
  7. 7Review the import summary — check imported, matched, and failed rows
  8. 8If errors exist, click Fix and reimport to download an error file and retry
💡Rep tip: Ask the seller if they have a customer list before assuming they don't. Many sellers have spreadsheets or exported lists from a previous system.
Add customers to Customer Directory ↗ Create customer groups and filters ↗
Square does not have a documented bulk team member import. Each team member must be added manually. Note: Square supports exporting team data, just not importing it.
  1. 1Staff → Team → Team members
  2. 2Click Add team member
  3. 3Enter the person's name and email address or phone number
  4. 4Enter job title, job details, and pay type
  5. 5Assign permissions — these control what staff can see and do
  6. 6Assign locations — this determines which POS they can access
  7. 7Generate a personal passcode for the team member
  8. 8Click Save to finish setup
  9. 9Repeat for each team member
💡Rep tip: Set permissions carefully. A new cashier should not have access to refunds or end-of-day reports. Use permission sets to speed up setup for staff with the same role.
